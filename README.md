# 書留記録(iPhoneだけで動く版・試作)

受領証を撮ると、iPhoneの中で読み取って記録に郵便1通ずつ登録します。
名前で検索すると、その郵便のお問い合わせ番号と、配達状況を開くボタンが出ます。
PCもサーバーも LINE も使いません。

## 使い方

1. 「受領証を撮る」を押して、紙全体が写るように撮る。
2. 読み取りが終わると、宛名と番号が記録に並ぶ。
3. 問い合わせが来たら、検索欄に名前・住所・郵便番号・番号の一部を入れる。
4. 「配達状況を開く」で、日本郵便の個別番号検索の結果ページが開く。

宛名の読み間違いは「宛名を直す」で直せます。直した内容で検索に当たるようになります。

## 情報がどこにあるか

| 情報 | 場所 |
|---|---|
| 受領証の写真 | どこにも保存しない。読み取りが終われば捨てる(写真アプリにも残らない) |
| 文字の読み取り | iPhoneの中で行う。外部のOCRやAIには送らない |
| 記録 | iPhoneのブラウザ内の保存領域だけ |
| 配達状況を開いたとき | お問い合わせ番号だけが日本郵便に送られる。宛名は送られない |

ページの先頭で、外部への通信をブラウザの仕組み(Content-Security-Policy)で禁止しています。
許可しているのは、このページ自身の部品(プログラムと読み取りモデル)の読み込みだけです。

## iPhoneに入れる方法

このフォルダは、ファイルを置くだけで動くWebページです。https で開ける場所に
フォルダの中身をそのまま置き、iPhoneのSafariで開きます。

- 置き場所は、ファイルを配るだけの場所で構いません(例: GitHub Pages)。
  置き場所に送られるのは部品の取得要求だけで、写真や記録は送られません。
- いちばん大きいファイルは約19MBです(読み取りモデルを2つに分けてあります)。
- 置き場所の持ち主はプログラムを書き換えられるので、自分で管理できる場所に置いてください。

Safariで開いたら、共有ボタンから **「ホーム画面に追加」** をして、以後は必ず
ホーム画面のアイコンから開いてください。理由は2つあります。

- Safariのまま使うと、しばらく開かなかったときに保存データ(記録)が消されることがある。
- ホーム画面から開く記録と、Safariで開く記録は別物になる。

初回は約65MBの部品を読み込みます。2回目以降は電波がなくても動きます。

## 記録について

- 同じお問い合わせ番号は二重に登録しません。
- 提出日は受領証の左下の発行日。読めなければ撮った日。
- 番号の末尾1桁の検算が合わないものは「番号要確認」と表示します。
- 提出日から100日を過ぎた行は自動で消えます(「書き出しと設定」で変更可)。
- 「Excelファイルに書き出す」で、記録を .xlsx として「ファイル」アプリなどに保存できます。
- ホーム画面のアイコンを削除したり、Safariの「履歴とWebサイトデータを消去」をすると
  記録も消えます。残したいときは先に書き出してください。

## まだ確かめられていないこと

- 動作を確かめたのはPCのブラウザ(Chromium)の上だけです。iPhoneのSafariではまだ動かしていません。
- 試した画像は、サンプルのスキャン画像と、それを斜めから撮った写真のように加工したものだけです。
- 読み取り位置はサンプルの様式(1枚に6枠、一般書留)に合わせてあります。
  様式が違う場合は `reader.js` 冒頭の割合を調整します。
- 番号は「11桁、末尾1桁は先頭10桁を7で割った余り」として読んでいます。
  簡易書留・特定記録でも同じかは実物で確認が必要です。
- 試験機では1枚あたり約20秒かかりました。iPhoneでの時間は未計測です。
